# 인하맵 나우 · 임시 미리보기

휴대폰에서 캠퍼스 3D 지도와 층별 이벤트·모임 화면을 확인하는 실행본입니다.

- 지도/게시판 2:1, 건물 선택 시 부드러운 줌인과 1:2 전환
- 건물 단독 보기, 층별 색 강조와 글 목록
- 2D 캠퍼스 전체 보기, 기기 내 글쓰기

건물과 실행 코드는 index.html에 포함됩니다. 배경 지도는 OpenStreetMap을 사용하며 인터넷 연결이 필요합니다. 게시글은 시연용 샘플과 해당 브라우저에 저장한 글입니다. 기본 내 위치는 캠퍼스 내 고정 미리보기 위치입니다.

로그인, 서버 저장, 공사·변경사항 실시간 갱신은 이 정적 미리보기에 포함되지 않습니다. 이 저장소에는 배포용 실행 파일만 들어 있습니다.

지도·건물 데이터 출처 표기는 앱의 지도 저작권 안내를 참고하세요.
